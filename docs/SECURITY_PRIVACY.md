# Security And Privacy

AfterFaith Guide should collect as little personal data as possible.

## Data Collection

The suggest-a-resource form collects:

- Title
- URL
- Resource type
- Optional email
- Notes

Email is optional and should only be used for clarification about a suggestion.

## Turnstile

Production suggestions require Cloudflare Turnstile verification before insertion into D1.

## No Accounts

The MVP must not include login, user accounts, public comments, forums, or public submissions.

## Logging

Avoid logging personal notes, email addresses, Turnstile tokens, or request bodies.
